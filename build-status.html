🚀 How to Run the Application

Option 1: Install Java 17 (Recommended)

  1. Download and install Java 17 from Adoptium
  2. Set JAVA_HOME to Java 17 installation directory
  3. Run the application:
cd "path\to\EcommerceSite-main"
.\mvnw.cmd clean install
.\mvnw.cmd spring-boot:run

Option 2: Use Java 24 with Compatibility Settings

  1. Set Maven to use Java 17 target while running on Java 24:
$env:MAVEN_OPTS = "--add-opens java.base/java.lang=ALL-UNNAMED"
.\mvnw.cmd clean compile -Dmaven.compiler.source=17 -Dmaven.compiler.target=17
